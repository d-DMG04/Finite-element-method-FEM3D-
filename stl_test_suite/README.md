# STL Test Suite — набор файлов для проверки импорта геометрий

Набор из 25 STL-файлов, покрывающий типичные edge cases и дефекты, с которыми сталкивается парсер/валидатор STL.

## Корректный baseline (sanity-check)

| Файл | Что проверяет | Ожидаемое поведение |
|---|---|---|
| `01_valid_cube_ascii.stl` | Чистый ASCII-куб, 12 треугольников | Импорт без ошибок |
| `18_valid_cube_binary.stl` | Чистый бинарный куб, 12 треугольников | Импорт без ошибок |

## Структура бинарного STL (для справки)

```
[80 байт]  header (произвольный, НЕ должен начинаться с "solid ", но многие нарушают)
[4 байта]  uint32 little-endian: количество треугольников N
N × [50 байт]:
    [12 байт] normal (3 × float32)
    [12 байт] vertex 1
    [12 байт] vertex 2
    [12 байт] vertex 3
    [2 байта] attribute byte count (обычно 0, иногда RGB-цвет)
```

Ожидаемый размер бинарного файла: `84 + 50 × N`.

## Минимальный чек-лист для парсера

1. Автоопределение ASCII vs binary **по размеру файла**, не по префиксу.
2. Обработка `NaN`, `Inf`, `-0` без падения.
3. Tolerance для определения вырожденности (рекомендуется ~1e-12 по площади).
4. Подсчёт ошибок vs warnings — не отказываться от всего файла из-за пары битых треугольников.
5. Сохранение исходной топологии при дедупликации (опция, не by-default).
6. UTF-8 для имён solid.
